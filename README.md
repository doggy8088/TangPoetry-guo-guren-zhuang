# 過故人莊 — 小玉與阿庭的農莊之約

給小學三年級小朋友的唐詩動畫課：透過「小玉邀請阿庭到農家作客」的故事，沉浸式認識〈過故人莊〉（孟浩然）的每個生字，再用「四張圖」記憶法背熟全詩。

## 成品
- **互動網頁**：`index.html`（直式 9:16 舞台，手機、電腦皆可）。
  啟動：`npm run serve` 後開 <http://localhost:5173/>。
  功能：播放／暫停、場景快選、進度列、生字表（23 張字卡＋語音）、背誦模式（四張圖＋漸進隱字）。
- **直式影片**：`out/guo-guren-zhuang.mp4`（1080×1920、30fps、H.264＋AAC，約 8 分 06 秒）。

## 內容結構（8 個場景、52 句旁白）
片頭 → 邀請（故人具雞黍，邀我至田家）→ 路上（綠樹村邊合，青山郭外斜）→ 開窗（開軒面場圃）→ 聊天（把酒話桑麻）→ 約定（待到重陽日，還來就菊花）→ 圖像記憶（四張圖）→ 背誦挑戰（填空＋全詩）。

生字（23）：過、故人、莊、具、雞黍、邀、至、田家、合、郭、斜、軒、面、場、圃、把、話、桑麻、待到、重陽、還來、就、菊花。

## 技術管線
| 步驟 | 指令 | 說明 |
|---|---|---|
| 劇本／分鏡 | `script/narration.json` | 每句旁白含 `visual` 分鏡、`vocab` 字卡、`recite` 詩句 |
| 語音 | `npm run tts` | Gemini `gemini-3.8-flash-tts`（需 `GEMINI_API_KEY`），含轉寫比對品管、靜音修剪、響度正規化，輸出 `audio/` 與 `script/timeline.json` |
| 背景音樂 | `npm run bgm` | 以 Node 合成的五聲音階音樂盒循環 |
| 網頁 | `npm run serve` | 靜態伺服器；動畫以 GSAP 單一時間軸驅動，`?render=1` 提供逐格渲染介面 |
| 影片 | `npm run render` | Playwright 逐格截圖 → ffmpeg 編碼並混音（`--preview` 可快速預覽） |
| 檢查 | `npm run snap -- 10 60 120` | 指定秒數截圖到 `out/snaps/` |

修改任何旁白文字後：`node scripts/tts.mjs --only <cueId>` → `npm run render`。

## 讀音約定
- 「斜」：只有詩句「青山郭外斜」與生字卡的「斜」字讀 ㄒㄧㄚˊ（xiá，古詩押麻韻的傳統讀法）；一般句子的「斜斜的／斜斜地」讀 ㄒㄧㄝˊ（xié）。
- 「郭」讀 ㄍㄨㄛ（guō）。
- 「還來」的「還」讀 ㄏㄞˊ（hái，再來）。
- 「場」字卡標 ㄔㄤˇ，與語音一致（TTS 無法穩定唸出 ㄔㄤˊ）。

TTS 模型對這些字會自動改回常用讀音，所以 `script/narration.json` 裡相關句子多了 `tts_text` 欄位：
畫面顯示用 `text`，實際朗讀與品管比對用 `tts_text`（以同音字強制讀音，例如 斜→霞、還→孩、郭→鍋）。
新增或修改句子時若有特殊讀音，同樣加上 `tts_text` 即可；重生後建議用拼音逐字轉寫再確認一次讀音。
